How this was measured and what to keep in mind
  • The suite is 704 circuit and target pairs, each at two optimization levels, run one job at a time for QUMO, Qiskit, TKET and Cirq, four times in a row. Figures are means across those runs.
  • Cirq has no built-in target gateset for several of the suite's targets, so 320 of its 704 pairs per level are unsupported and 5 failed. Its ratios cover only the pairs it compiled.
  • The machine was also running other work (load average about 3 to 3.5), so absolute times are indicative. Ratios between SDKs held across all four runs.
  • Peak memory includes memory the worker process kept from earlier jobs, including the statevector check that runs between compiles. Read it as a comparison between SDKs, not as the cost of one compile. Idle memory is stable across runs.
  • Two-qubit gate counts are in the source data. In the mean, every other SDK produced more two-qubit gates than QUMO for the same job.
