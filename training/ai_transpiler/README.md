# Training QUMO's AI-transpiler models

QUMO's AI transpiler (docs/AI_TRANSPILER.md) runs natively in Mojo and needs
no Python at runtime. This directory holds the *training-time* code that
produces the models under `models/ai_transpiler/`:

| directory | produces | runtime consumer |
|---|---|---|
| `synth/` | synthesis policies (`qumo.rlsynth.v0`) for permutation, linear-function, Clifford and Pauli-network blocks, trained with qiskit-gym 0.4.1 PPO | `qumo/compiler/policy.mojo`, `policy_synth.mojo` (passes `perm_synth`, `linear_synth`, `clifford_synth`, `pauli_network`) |
| `route/` | the learned router (`qumo.rlroute.v0`), trained by behaviour cloning / DAgger in QUMO's own routing environment (qiskit-gym has no routing env) | `qumo/compiler/ai_route.mojo` (`route(..., policy=auto)`) |
| `common/` | shared container writer (`export.py`: manifest.json + weights.bin, f16 matrices, 64-byte aligned tensors, FNV-1a64 in the manifest, sha256 in INDEX.json), topology parser and WL hash (`topology.py`), symmetry tables (`symmetry.py`), numpy reference environments (`refenv.py`), test-fixture generator (`make_fixtures.py`) | |

Everything is Apache-2.0. qiskit-gym 0.4.1 and its RL engine twisterl 0.5.1
(Apache-2.0) are used **only here**; no IBM model weights and no code from
`qiskit-ibm-ai-local-transpiler` are used. The trained weights are QUMO's.

## Setup

```bash
uv venv training/ai_transpiler/.venv --python 3.12
uv pip install --python training/ai_transpiler/.venv/bin/python -r training/ai_transpiler/requirements.txt
```

(`AI_TRAIN_PY` in the Makefile points at `training/ai_transpiler/.venv/bin/python`.)

## Make targets

| target | what it does | budget |
|---|---|---|
| `make train-ai` | `train-ai-synth` + `train-ai-route`, then `make models-verify` | hard caps: synthesis 8 h, router 3 h (Apple M5, 10 cores) |
| `make train-ai-synth` | trains, evaluates and exports every synthesis model of the ledger below; a model is exported only if it beats the greedy synthesizer (drop rule) | `AI_SYNTH_BUDGET_S` (28800 s) |
| `make train-ai-route` | teacher data -> behaviour cloning -> one DAgger round -> export `route_mlp_h64_v1` (a reduced version of the recipe in `route/README.md`) | `AI_ROUTE_BUDGET_S` (10800 s) |
| `make models-verify` | sha256 of every `weights.bin` against its INDEX.json; also flags weights not listed in any registry | seconds |

None of these is part of `make test`. Training is not bit-reproducible
(twisterl collects rollouts with an unseeded thread RNG); models are therefore
fixed, hashed artefacts, and QUMO's *inference* is fully seeded.

## Synthesis models (`synth/`)

`synth/train.py --kind {perm,lf,clifford,pauli} --topology <spec> --budget-s S --out RUN`
runs time-bounded PPO (curriculum on scramble difficulty up to `--diff-max`,
default 256) with qiskit-gym's `BasicPolicy` (sparse embedding 512 -> 256 ->
action / value heads). `synth/eval.py` / `synth/eval_blocks.mojo` compare the
model (greedy and beam-8 search in QUMO's Mojo inference) with QUMO's exact
and greedy synthesizers on 100 seeded blocks; `synth/export_model.py RUN --id
<id> --out models/ai_transpiler/synth --dtype f16` writes the container and
rebuilds `INDEX.json`.

Drop rule: a model is kept only if its beam-8 cost is below the greedy
synthesizer's on the evaluation set. Exact search covers the smallest blocks
(permutations <= 10 qubits, linear functions <= 5, Cliffords <= 4), so models
matter for the 6-12 qubit fragments.

The ledger (budgets, wall times, final curriculum difficulty, evaluation and
keep / drop decision per model) is reproduced in docs/AI_TRANSPILER.md
("Training budgets and retraining").

## Router (`route/`)

See `route/README.md`: QUMO's routing environment (active swaps over 8
topological layers, 128-int sign observation, 128 -> 64 -> 16 MLP) mirrored
bit-exactly in Python (`route_env.py`), seeded teacher rollouts generated by
`route_tool.mojo gen`, behaviour cloning on soft teacher labels
(`train_route.py`), DAgger, optional PPO fine-tuning (`train_ppo.py`; it made
the policy worse and was dropped), export with test vectors (`export_npz.py`).
Held out of all training: every circuit of `bench/neutral/circuits` and every
synthetic seed >= 800000.

## Adding a model

1. Train into a scratch run directory (never commit raw runs; `.gitignore`
   excludes `training/ai_transpiler/**/runs/` and checkpoints).
2. Evaluate against the greedy synthesizer; apply the drop rule.
3. Export into `models/ai_transpiler/{synth,route}/<id>/` (rebuilds INDEX.json).
4. `make models-verify` and `make test` (tests/test_policy.mojo and
   tests/test_ai_route.mojo replay each model's embedded test vectors).
5. Keep the whole `models/ai_transpiler` tree under 10 MB.
